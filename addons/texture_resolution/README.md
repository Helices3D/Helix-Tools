# Texture Resolution

Create half-resolution alternatives for large scene textures and switch between
the originals and smaller copies. **Setup and Run** scans scene image references,
preserves original files and pixels, and tracks each alternative in the `.blend`.
The minimum size is configurable; either dimension reaching 4000 px qualifies
by default. Memory figures estimate active texture payload, not measured RAM or
VRAM use.

For **Blender 5.2.2 LTS**. Install the standalone ZIP or use the complete
Helix Tools suite. Controls appear under **3D View → Sidebar → Helix Tools**.

See the [usage guide](../../docs/usage.md#texture-resolution) for supported images,
shared scene resources, output files, and memory-estimate limits.
