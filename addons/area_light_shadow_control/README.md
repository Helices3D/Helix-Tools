# Light Size and Shadow Control

Enable Eevee shadows for scene or collection lights in one click. Adjust source
size from saved baselines, tune shadow detail, and try reversible render presets
with optional startup backups.

Targets **Blender 5.2.2 LTS**. Open **3D Viewport → Sidebar (`N`) → Helix Tools → Light Control**.

See the [usage guide](https://github.com/Helices3D/Helix-Tools/blob/main/docs/usage.md#light-size-and-shadow-control) for targeting, sizing, and restore behavior.

For automatic installation of newer published versions, use **Preferences →
Add-ons → Check for Updates** in an enabled Helix extension, then restart Blender
when prompted. See the [update guide](https://github.com/Helices3D/Helix-Tools/blob/main/docs/usage.md#updates).
