# Camera Timeline Culler

Temporarily hide geometry outside all sampled camera views and restore its original memberships and visibility.

Targets **Blender 5.2.2 LTS**. Open **3D Viewport → Sidebar (`N`) → Helix Tools**.

For usage, migration, and validation details, see the [Helix Tools repository](https://github.com/Helices3D/Helix-Tools).
